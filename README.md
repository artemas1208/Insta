# IG Lead Scout

Расширение для Microsoft Edge (и любого Chromium-браузера), которое помогает
искать экспертов в Instagram: подсвечивает уже просмотренные профили,
показывает краткую статистику по наведению и умеет быстро проверять
профиль на наличие ссылки на Telegram.

## Установка (Edge)

1. Распакуйте архив в постоянную папку (не удаляйте её после установки —
   Edge подключает расширение прямо к этой папке).
2. Откройте `edge://extensions/`.
3. Включите «Режим разработчика» (переключатель внизу слева).
4. Нажмите «Загрузить распакованное» и выберите папку с `manifest.json`.
5. Закрепите иконку расширения — через неё открываются настройки.

## Что делает

- Точка на аватарке в любом списке (подписчики/подписки/поиск):
  серая — не заходили, синяя — заходили но данные не извлечены,
  жёлтая — проверен, TG не найден, зелёная — есть Telegram.
- Наведение на профиль в списке — всплывающая карточка с числом
  подписчиков и ссылкой на TG (если есть).
- Значок ⚡ на аватарке — быстрая проверка: открывает профиль отдельной
  фоновой вкладкой, читает статистику/bio, закрывает вкладку сама.
  Есть пауза между проверками (настраивается в попапе) — специально,
  чтобы не создавать всплеск активности на аккаунте.
- Клик по строке в модалке подписчиков/подписок — открывает профиль в
  новой вкладке или во втором окне (сплит-экран), а не заменяет текущую
  страницу, поэтому поиск в модалке не сбрасывается.
- Панель фильтров прямо в модалке: мин. число подписчиков, только с TG,
  скрыть уже проверенных.
- Экспорт накопленной базы в CSV — через попап расширения.

## Если что-то не подсвечивается

Instagram периодически меняет вёрстку. Если точки/фильтры перестали
работать — правой кнопкой по элементу → «Просмотреть код» и пришлите
фрагмент HTML, будет проще поправить селекторы.
